Use quizzes well

Retrieval beats rereading

Try answering before opening a lesson. The effort to recall an idea helps reveal what is secure and what still feels vague.

  1. Answer unaided

    Choose the best answer from memory before checking notes or a CAD interface.

  2. Read the reason

    Use the explanation to compare your reasoning, not only the selected option.

  3. Apply once

    Return to a module and perform one small action that uses the missed concept.

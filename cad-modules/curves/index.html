Curves are fundamental entities in CAD. They are used to describe edges, profiles, trajectories and design features. A curve may be represented explicitly, implicitly or parametrically. Parametric representation is the most common in CAD.

Parametric Representation of Curves

A parametric curve in two or three dimensions is written as

\[ \mathbf r(u)= \begin{bmatrix} x(u)\\y(u) \end{bmatrix} \quad \text{or} \quad \mathbf r(u)= \begin{bmatrix} x(u)\\y(u)\\z(u) \end{bmatrix}, \]

where $u$ is the parameter.

For example, a circle of radius $R$ centered at the origin can be represented as

\[ \mathbf r(u)= \begin{bmatrix} R\cos u\\ R\sin u \end{bmatrix}, \qquad 0\le u\le 2\pi. \]

A straight line segment between points $\mathbf P_0$ and $\mathbf P_1$ is

\[ \mathbf r(u)=(1-u)\mathbf P_0+u\mathbf P_1, \qquad 0\le u\le 1. \]

Key Idea

Parametric curves are natural for CAD because they allow finite curve segments, easy differentiation, and direct construction from control points.

Differential Geometry for CAD

Differential geometry provides the mathematical language for describing the local shape of curves and surfaces. In CAD, these ideas are useful for understanding tangents, normals, curvature, smoothness, surface fairness, developability and geometric continuity.

Differential Geometry of Curves

A parametric space curve is a vector-valued function

\[ \mathbf r(u)= \begin{bmatrix} x(u)\\y(u)\\z(u) \end{bmatrix}, \qquad u\in(u_0,u_1). \]

The scalar variable \(u\) is called the parameter of the curve.

The derivative of the curve with respect to \(u\) is

\[ \mathbf r'(u)=\frac{d\mathbf r}{du}. \]

This vector is tangent to the curve. In mechanics terminology, if \(u\) is treated as time, then

\[ \mathbf v=\mathbf r'(u) \]

is the velocity,

\[ \mathbf a=\mathbf r''(u) \]

is the acceleration, and

\[ \mathbf b=\mathbf r'''(u) \]

is the jerk.

The speed of the parametrization is

\[ c=\|\mathbf r'(u)\|. \]

The unit tangent vector is

\[ \hat{\mathbf T} = \frac{\mathbf r'(u)}{\|\mathbf r'(u)\|} = \frac{\mathbf r'(u)}{c}. \]

Thus,

\[ \mathbf r'(u)=\mathbf v=c\hat{\mathbf T}. \]

Key Idea

The derivative \(\mathbf r'(u)\) gives the tangent direction and the speed of traversal of the curve. The unit tangent vector contains only direction information, while \(c=\|\mathbf r'(u)\|\) contains speed information.

Arc Length Parametrization

The arc length of a curve is

\[ s=\int c\,du = \int \|\mathbf r'(u)\|\,du. \]

Since

\[ c=\frac{ds}{du}, \]

we have

\[ \frac{du}{ds}=\frac{1}{c}. \]

If the curve is reparametrized using arc length \(s\), then

\[ \frac{d\mathbf r}{ds} = \frac{d\mathbf r}{du}\frac{du}{ds} = \frac{\mathbf r'(u)}{c}. \]

Therefore,

\[ \boxed{ \frac{d\mathbf r}{ds}=\hat{\mathbf T} } \]

Remark

Arc length is a natural parameter for a curve because the speed with respect to \(s\) is one:

\[ \left\|\frac{d\mathbf r}{ds}\right\|=1. \]

This simplifies many differential-geometric formulas.

Curvature

Curvature measures how rapidly the tangent direction changes as one moves along the curve. For an arc-length parametrized curve,

\[ \frac{d\hat{\mathbf T}}{ds} \]

is perpendicular to \(\hat{\mathbf T}\). Hence, it points in the normal direction.

The curvature \(\kappa\) is defined by

\[ \boxed{ \frac{d\hat{\mathbf T}}{ds} = \kappa \hat{\mathbf N} } \]

where \(\hat{\mathbf N}\) is the principal normal vector.

Thus,

\[ \kappa= \left\| \frac{d\hat{\mathbf T}}{ds} \right\|. \]

The radius of curvature \(\rho\) is

\[ \boxed{ \rho=\frac{1}{\kappa}. } \]

Since

\[ \hat{\mathbf T}\cdot\hat{\mathbf T}=1, \]

differentiating with respect to \(s\) gives

\[ 2\hat{\mathbf T}\cdot\frac{d\hat{\mathbf T}}{ds}=0. \]

Therefore,

\[ \hat{\mathbf T}\cdot\hat{\mathbf N}=0. \]

Key Idea

The tangent vector \(\hat{\mathbf T}\) and the principal normal vector \(\hat{\mathbf N}\) are perpendicular:

\[ \hat{\mathbf T}\cdot\hat{\mathbf N}=0. \]

For a general parameter \(u\), since

\[ \mathbf v=c\hat{\mathbf T}, \]

the acceleration is

\[ \mathbf a = \frac{d}{du}(c\hat{\mathbf T}) = \frac{dc}{du}\hat{\mathbf T} + c\frac{d\hat{\mathbf T}}{du}. \]

Using

\[ \frac{d\hat{\mathbf T}}{du} = \frac{d\hat{\mathbf T}}{ds}\frac{ds}{du} = \kappa\hat{\mathbf N}c, \]

we obtain

\[ \boxed{ \mathbf a = \frac{dc}{du}\hat{\mathbf T} + c^2\kappa\hat{\mathbf N}. } \]

Thus, acceleration has a tangential component and a normal component.

Binormal and Torsion

The binormal vector is defined as

\[ \hat{\mathbf B} = \hat{\mathbf T}\times \hat{\mathbf N}. \]

The three mutually perpendicular unit vectors

\[ \hat{\mathbf T},\quad \hat{\mathbf N},\quad \hat{\mathbf B} \]

form the Frenet frame of the curve.

Using

\[ \mathbf v=c\hat{\mathbf T}, \]

and

\[ \mathbf a= \frac{dc}{du}\hat{\mathbf T} + c^2\kappa\hat{\mathbf N}, \]

we get

\[ \mathbf v\times\mathbf a = c\hat{\mathbf T} \times \left( \frac{dc}{du}\hat{\mathbf T} + c^2\kappa\hat{\mathbf N} \right). \]

Since

\[ \hat{\mathbf T}\times\hat{\mathbf T}=\mathbf 0, \]

we obtain

\[ \mathbf v\times\mathbf a = c^3\kappa(\hat{\mathbf T}\times\hat{\mathbf N}). \]

Therefore,

\[ \boxed{ \mathbf v\times\mathbf a = c^3\kappa\hat{\mathbf B}. } \]

Taking magnitudes,

\[ \boxed{ c^3\kappa=\|\mathbf v\times\mathbf a\|. } \]

Torsion measures how rapidly the binormal vector changes along the curve. It is defined by

\[ \boxed{ \frac{d\hat{\mathbf B}}{ds} = -\tau\hat{\mathbf N}. } \]

Here \(\tau\) is the torsion of the curve.

Remark

Curvature measures bending of the curve. Torsion measures twisting of the curve out of the osculating plane.

Frenet–Serret Formulae

The Frenet–Serret formulae describe how the moving frame

\[ \{\hat{\mathbf T},\hat{\mathbf N},\hat{\mathbf B}\} \]

changes along the curve:

\[ \boxed{ \frac{d\hat{\mathbf T}}{ds} = \kappa\hat{\mathbf N} } \]
\[ \boxed{ \frac{d\hat{\mathbf B}}{ds} = -\tau\hat{\mathbf N} } \]
\[ \boxed{ \frac{d\hat{\mathbf N}}{ds} = \tau\hat{\mathbf B} - \kappa\hat{\mathbf T}. } \]

Key Idea

The Frenet–Serret formulae give a complete local description of the shape of a space curve in terms of curvature \(\kappa\) and torsion \(\tau\).

A useful identity involving velocity, acceleration and jerk is

\[ \boxed{ \mathbf v\cdot(\mathbf a\times\mathbf b) = c^6\kappa^2\tau. } \]

For arc-length parametrization, where \(c=1\), this reduces to

\[ \mathbf r'(s)\cdot \left( \mathbf r''(s)\times\mathbf r'''(s) \right) = \kappa^2\tau. \]

Bezier Curves

A Bezier curve of degree $n$ is defined using $n+1$ control points

\[ \mathbf P_0,\mathbf P_1,\ldots,\mathbf P_n. \]

The curve is

\[ \mathbf r(u)=\sum_{i=0}^{n} B_{i,n}(u)\mathbf P_i, \qquad 0\le u\le 1, \]

where $B_{i,n}(u)$ are Bernstein basis polynomials:

\[ B_{i,n}(u)= \binom{n}{i}u^i(1-u)^{n-i}. \]

Example

A quadratic Bezier curve has three control points $\mathbf P_0,\mathbf P_1,\mathbf P_2$ and is given by

\[ \mathbf r(u)=(1-u)^2\mathbf P_0+2u(1-u)\mathbf P_1+u^2\mathbf P_2. \]

Properties

Bezier curves have the following important properties.

  1. Endpoint interpolation:

    \[ \mathbf r(0)=\mathbf P_0, \qquad \mathbf r(1)=\mathbf P_n. \]

  2. Convex hull property: The curve lies inside the convex hull of its control points.

  3. Affine invariance: Applying an affine transformation to the control points gives the same result as applying it to the curve.

  4. Variation diminishing property: A line intersects the curve no more times than it intersects the control polygon.

  5. Endpoint tangent property:

    \[ \mathbf r'(0)=n(\mathbf P_1-\mathbf P_0), \qquad \mathbf r'(1)=n(\mathbf P_n-\mathbf P_{n-1}). \]

Remark

The control polygon gives a visual handle for shaping the curve. Moving a control point changes the shape of the curve.

Derivative of a Bezier Curve

The derivative of a Bezier curve of degree $n$ is another Bezier curve of degree $n-1$:

\[ \mathbf r'(u)= n\sum_{i=0}^{n-1}B_{i,n-1}(u)(\mathbf P_{i+1}-\mathbf P_i). \]

Thus, the derivative control points are

\[ \mathbf Q_i = n(\mathbf P_{i+1}-\mathbf P_i), \qquad i=0,1,\ldots,n-1. \]

Key Idea

The derivative of a Bezier curve is controlled by the differences between consecutive control points.

Curve Subdivision

Bezier curve subdivision splits a curve into two Bezier curves at a parameter value $u=t$. The de Casteljau algorithm is used for this purpose.

Starting from control points

\[ \mathbf P_i^{(0)}=\mathbf P_i, \]

define recursively

\[ \mathbf P_i^{(r)}=(1-t)\mathbf P_i^{(r-1)} +t\mathbf P_{i+1}^{(r-1)}. \]

The final point

\[ \mathbf P_0^{(n)} \]

is the point on the Bezier curve at parameter $t$.

The left and right sets of generated points form the control points of the two subdivided curves.

Remark

Subdivision is useful in rendering, intersection calculations, adaptive refinement and geometric modeling.

Degree Elevation

Degree elevation converts a Bezier curve of degree $n$ into an equivalent curve of degree $n+1$.

Let the old control points be

\[ \mathbf P_0,\mathbf P_1,\ldots,\mathbf P_n. \]

The new control points are

\[ \mathbf Q_0=\mathbf P_0, \qquad \mathbf Q_{n+1}=\mathbf P_n, \]

and

\[ \mathbf Q_i= \frac{i}{n+1}\mathbf P_{i-1} + \left(1-\frac{i}{n+1}\right)\mathbf P_i, \qquad i=1,2,\ldots,n. \]

Key Idea

Degree elevation changes the control polygon but not the geometric curve.

Rational Bezier Curves

A rational Bezier curve uses weights $w_i$ associated with control points:

\[ \mathbf r(u)= \frac{ \sum_{i=0}^{n} w_i B_{i,n}(u)\mathbf P_i }{ \sum_{i=0}^{n} w_i B_{i,n}(u) }. \]

When all weights are equal, the rational Bezier curve reduces to the ordinary polynomial Bezier curve.

Weights provide additional shape control. Increasing a weight pulls the curve closer to the corresponding control point.

Homogeneous Coordinates and Rational Curves

Rational curves can be understood as projections of polynomial curves in homogeneous coordinates.

For a point

\[ \mathbf P_i=(x_i,y_i,z_i) \]

with weight $w_i$, define the homogeneous point

\[ \mathbf P_i^h=(w_ix_i,w_iy_i,w_iz_i,w_i). \]

Construct the polynomial Bezier curve in homogeneous space:

\[ \mathbf R^h(u)=\sum_{i=0}^{n}B_{i,n}(u)\mathbf P_i^h. \]

If

\[ \mathbf R^h(u)=(X(u),Y(u),Z(u),W(u)), \]

then the rational curve in ordinary space is

\[ \mathbf r(u)= \left( \frac{X(u)}{W(u)}, \frac{Y(u)}{W(u)}, \frac{Z(u)}{W(u)} \right). \]

Rational Representation of Circle and Ellipse

Polynomial Bezier curves cannot exactly represent a circle. Rational Bezier curves can.

A quarter circle of radius $R$ from $(R,0)$ to $(0,R)$ can be represented using a quadratic rational Bezier curve with

\[ \mathbf P_0=(R,0), \qquad \mathbf P_1=(R,R), \qquad \mathbf P_2=(0,R), \]

and weights

\[ w_0=1, \qquad w_1=\frac{1}{\sqrt{2}}, \qquad w_2=1. \]

The corresponding curve is

\[ \mathbf r(u)= \frac{ (1-u)^2w_0\mathbf P_0 +2u(1-u)w_1\mathbf P_1 +u^2w_2\mathbf P_2 }{ (1-u)^2w_0+2u(1-u)w_1+u^2w_2 }. \]

An ellipse can be obtained by applying non-uniform scaling to a circle.

Key Idea

Conic sections such as circles, ellipses, parabolas and hyperbolas require rational representations for exact CAD modeling.

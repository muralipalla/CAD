01 / WHY CONJUGATION WORKS

Bring the axis back. Rotate. Put it back.

Let \(R_n=\operatorname{Rot}(\vec n,\theta_n)\), \(R_m=\operatorname{Rot}(\vec m,\theta_m)\), and \(\vec m'=R_n\vec m\). Directions need not be perpendicular. For any test vector \(\vec v\), read the product from right to left:

1

Undo the axis motion

\[\vec v_1=R_n^T\vec v\]

The same inverse rotation takes \(\vec m'\) back to \(\vec m\).

2

Rotate about m

\[\vec v_2=R_m\vec v_1\]

Apply the original angle \(\theta_m\) about the original axis.

3

Restore the axis motion

\[\vec v_3=R_n\vec v_2\]

Return the axis to \(\vec m'\). The angle is still \(\theta_m\).

\[\boxed{\operatorname{Rot}(R_n\vec m,\theta_m)=R_nR_mR_n^T}\]

The asymmetric kettle makes the changing orientation easy to see. Matching one solid object is still an illustration rather than a proof; the vector argument applies to every vector, and the live matrix comparison checks all nine entries.

A proof for any direction n, using Rodrigues’ formula

For a unit direction \(\hat m\), let \([\hat m]_\times\vec v=\hat m\times\vec v\). With \(c=\cos\theta_m\) and \(s=\sin\theta_m\),

\[R_m=cI+(1-c)\hat m\hat m^T+s[\hat m]_\times.\]

Any proper rotation \(Q\) preserves cross products, so \(Q[\hat m]_\times Q^T=[Q\hat m]_\times\). Hence

\[QR_mQ^T=cI+(1-c)(Q\hat m)(Q\hat m)^T+s[Q\hat m]_\times=\operatorname{Rot}(Q\hat m,\theta_m).\]

Take \(Q=R_n\). No alignment of \(\vec n\) with X, Y, or Z is assumed.

02 / REUSE THE SAME IDENTITY

Each new axis follows the body

Let \(R_\ell=\operatorname{Rot}(\vec\ell,\theta_\ell)\), \(R_m=\operatorname{Rot}(\vec m,\theta_m)\), and \(R_n=\operatorname{Rot}(\vec n,\theta_n)\). These are three directions attached to a rigid body, initially expressed in world coordinates. They need not form an orthogonal coordinate frame.

1

First: about ℓ

\[A_1=R_\ell,\qquad\vec m'=A_1\vec m.\]
2

Then: about the moved direction m′

\[R_{m'}=A_1R_mA_1^T\]
\[A_2=R_{m'}A_1=A_1R_m\underbrace{A_1^TA_1}_{I}=R_\ell R_m.\]
3

Finally: about the twice-moved direction n″

\[\vec n''=A_2\vec n=R_\ell R_m\vec n,\qquad R_{n''}=A_2R_nA_2^T.\]
\[A_3=R_{n''}A_2=A_2R_n\underbrace{A_2^TA_2}_{I}=R_\ell R_mR_n.\]
Expand the complete product and see the cancellations
\[R_{\mathrm{intrinsic}}=(R_\ell R_mR_nR_m^TR_\ell^T)(R_\ell R_mR_\ell^T)R_\ell\]
\[=R_\ell R_mR_nR_m^T\underbrace{R_\ell^TR_\ell}_{I}R_m\underbrace{R_\ell^TR_\ell}_{I}\]
\[=R_\ell R_mR_n\underbrace{R_m^TR_m}_{I}=R_\ell R_mR_n.\]
\[\boxed{R_{\mathrm{intrinsic}}=R_\ell R_mR_n=R_{\mathrm{extrinsic,\ reversed}}}\]

In time, the intrinsic sequence is \(\ell\to m'\to n''\). The extrinsic sequence is \(n\to m\to\ell\) about the original fixed directions, with each angle kept with its axis. Both produce the same final orientation.

03 / THE FAMILIAR COORDINATE AXES

Intrinsic XYZ is extrinsic ZYX

Now set \(\vec\ell=\hat x\), \(\vec m=\hat y\), \(\vec n=\hat z\), with angles \(\alpha,\beta,\gamma\). The body and world coordinate frames initially coincide.

Intrinsic · moving body axes

Chronological order:

\[X(\alpha)\ \to\ Y'(\beta)\ \to\ Z''(\gamma)\]
\[A_1=R_x(\alpha),\quad A_2=R_x(\alpha)R_y(\beta)\]
\[A_3=R_x(\alpha)R_y(\beta)R_z(\gamma).\]

Extrinsic · fixed world axes

Chronological order:

\[Z(\gamma)\ \to\ Y(\beta)\ \to\ X(\alpha)\]
\[B_1=R_z(\gamma),\quad B_2=R_y(\beta)R_z(\gamma)\]
\[B_3=R_x(\alpha)R_y(\beta)R_z(\gamma).\]
\[\boxed{\text{Intrinsic }XYZ(\alpha,\beta,\gamma)\equiv\text{Extrinsic }ZYX(\gamma,\beta,\alpha)}\]

Reverse the axis–angle pairs, not just the letters. Choosing the same chronological order generally produces a different final orientation. Special cases such as zero angles can still agree. The dropdown above applies the same rule to all six orders with distinct axes; these equations illustrate XYZ.

The coordinate-axis matrices
\[R_x(\alpha)=\begin{bmatrix}1&0&0\\0&\cos\alpha&-\sin\alpha\\0&\sin\alpha&\cos\alpha\end{bmatrix}\]\[R_y(\beta)=\begin{bmatrix}\cos\beta&0&\sin\beta\\0&1&0\\-\sin\beta&0&\cos\beta\end{bmatrix}\]\[R_z(\gamma)=\begin{bmatrix}\cos\gamma&-\sin\gamma&0\\\sin\gamma&\cos\gamma&0\\0&0&1\end{bmatrix}\]

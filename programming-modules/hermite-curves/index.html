Interactive programming module 03

Hermite Curves

A cubic Hermite segment is controlled directly by its two endpoints and endpoint tangent vectors. Drag the circular endpoints or the diamond tangent handles.

  • Two endpoints
  • Two tangent vectors
  • Python or MATLAB

Window 1 · Code

Hermite program

The displayed endpoint and tangent arrays update while you drag. Both versions evaluate the same four cubic Hermite basis functions.

hermite.py

Window 2 · Graphics

Set endpoints and tangents

endpointstangent handlesHermite curve

After clearing, click twice to place P0 and P1. Drag endpoint circles or tangent handles. Arrow keys move the selected handle.

Learning point

Position and direction are independent inputs

The curve interpolates both endpoints. Moving a tangent handle changes the endpoint direction and speed without changing the corresponding endpoint position.

Traversal logic

Algorithms on WEDS

Adapted from the vertex and face inquiries in C.-K. Shene’s Mesh Basics slides, especially slides 35–42.

01 · Around a vertex

Incident edges and neighboring vertices

Main Inquiry: Find all edges incident to a given vertex and all vertices connected to it.

seed = any edge touching vertex X
edge = seed
repeat:
    emit edge and its other endpoint
    if edge.V1 == X:
        edge = edge.LeftPrevious
    else:
        edge = edge.RightPrevious
until edge == seed

Each step stays at X and crosses to the next adjacent face. The result has one edge per vertex incident.

02 · Around a face

Boundary edges and vertices

Main Inquiry: Find all edges and vertices that bound a given face.

seed = any edge touching face F
edge = seed
repeat:
    emit edge
    if edge.LeftFace == F:
        emit edge.V1
        edge = edge.LeftNext
    else:
        emit edge.V2
        edge = edge.RightNext
until edge == seed

The vertices are emitted in the face orientation stored by the exporter. A face with multiple loops would require one seed per loop.

The lecture slides describe the same local traversal idea with predecessor/successor names tied to their illustrated winding. Our exporter defines Previous and Next in each face’s stored boundary order, so the exact pointer choices above are the ones for this CSV format.

Data contract

What the CSV stores

Each row is one edge. The first column is its ID; the next eight columns hold its endpoints, two incident faces, and four wing links. All record values are non-negative, zero-based integers without V, E, or F prefixes. The exported tetrahedron, cube, and pentagonal prism are closed orientable meshes, so every edge has both incident faces.

ColumnsMeaning
Edge, V1, V2Edge ID and its chosen direction from start vertex V1 to end vertex V2.
Left Face, Right FaceIncident face IDs relative to that direction.
Left Previous, Left NextPrevious and next edge IDs in the stored left-face boundary order.
Right Previous, Right NextPrevious and next edge IDs in the stored right-face boundary order.

The CSV supplies the edge table but not separate vertex and face tables. The browser, Python, and MATLAB examples scan it once to choose one seed edge for each vertex and face; each later query walks only local wing pointers.

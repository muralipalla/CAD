Coons Patch

Window 3 · Code

Construct the same patch

The program uses the current 12 unique controls. Shared corner indices enforce boundary compatibility.

Construction

Add two ruled blends, subtract the duplicated corners

\[\mathbf r(u,v)=(1-u)\mathbf C_0(v)+u\mathbf C_1(v)+(1-v)\mathbf D_0(u)+v\mathbf D_1(u)-\mathbf B(u,v).\]

The first pair sweeps between the left and right boundaries; the second sweeps between the bottom and top. Both include the bilinear corner surface, so \(\mathbf B\) is subtracted once. This makes \(\mathbf r\) reproduce each input curve along its corresponding edge.

The four boundaries here are cubic Bézier curves. Their endpoint controls are shared, so the corner compatibility conditions cannot be broken while editing.

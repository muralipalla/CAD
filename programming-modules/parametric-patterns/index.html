Read the algorithm

One loop, four ideas

  • ParameterA named input such as count or radius controls a whole family of valid patterns.
  • IterationThe loop repeats the same point-building operation once for each instance.
  • Angle conversionMost programming language trigonometry functions expect radians rather than degrees.
  • Coordinate calculationx = r cos θ and y = r sin θ convert each polar position to Cartesian coordinates.

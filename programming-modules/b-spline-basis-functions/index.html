B-Spline Basis Functions

Enter a knot vector, choose the order, and compare clamped, not-clamped, periodic, and fully custom bases. A second graph computes the sum of every possible basis function over the plotted interval.

  • Cox–de Boor iteration
  • Custom and periodic knots
  • Partition of unity

Section 1 · Formula from the HTML notes

Cox–de Boor recursion

Open B-Spline theory
Degree\(n\)
Order\(m=n+1\)
Knot vector\(U=\{u_0,\ldots,u_{k-1}\}\)
Basis\(N_{m,i}(u)\)
01 · Start

Order-one basis

\[ N_{1,i}(u)= \begin{cases} 1, & u_i\le u<u_{i+1},\\ 0, & \text{otherwise}. \end{cases} \]
02 · Iterate for \(m>1\)

Build order m from order m − 1

\[ \boxed{ N_{m,i}(u) = \frac{u-u_i}{u_{i+m-1}-u_i}N_{m-1,i}(u) + \frac{u_{i+m}-u}{u_{i+m}-u_{i+1}}N_{m-1,i+1}(u) } \]

If a denominator is zero, the corresponding term is taken as zero.

Support
\[N_{m,i}(u)\neq 0\quad\text{only on}\quad [u_i,u_{i+m}).\]
Partition of unity on the active domain
\[\sum_{i=0}^{c-1}N_{m,i}(u)=1,\qquad u\in [u_{m-1},u_{k-m}].\]
Periodic mode

The same Cox–de Boor recursion is evaluated on an extended knot vector. The module then combines effective basis terms whose indices differ by c, so each displayed basis wraps across one period and the sum remains one.

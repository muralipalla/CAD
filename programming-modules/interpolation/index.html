Interactive programming module 01

Global Interpolation

Place data points in click order and drag them while a chord-length-parametrized polynomial is rebuilt. Compare the curve with the points’ convex hull.

  • Click and drag
  • Python or MATLAB
  • Global Lagrange polynomial

Learning point

Interpolation does not guarantee a convex-hull curve

The polynomial passes through every data point, but portions can overshoot beyond the convex hull. Moving one point can change the curve everywhere because this interpolant is global.
